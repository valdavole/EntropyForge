# Pravidla spolupráce

Projekt vítá věcné, slušné a technicky podložené příspěvky bez ohledu na
zkušenosti autora.

## Očekávané chování

- Kritizuj kód a tvrzení, nikoli člověka.
- Bezpečnostní závěry dokládej reprodukovatelným postupem.
- Přiznej nejistotu a oprav chybu, když se objeví lepší důkaz.
- Respektuj soukromí, autorská práva a licenci.
- Udržuj diskusi relevantní k projektu.

## Nepřijatelné chování

- urážky, obtěžování nebo diskriminace,
- zveřejnění cizích osobních údajů,
- úmyslné vložení škodlivého kódu nebo tajných údajů,
- opakované zavádějící bezpečnostní či certifikační tvrzení,
- zneužívání issue a pull requestů ke spamu.

Správce může nevhodný obsah upravit, skrýt nebo odstranit a omezit účast
uživatele. Citlivý incident oznam neveřejně přes kontakt na GitHub
profilu správce.
