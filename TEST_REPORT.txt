1. VERDIKT
----------

Python i HTML zachovávají všechny funkce 3.1 a přidávají shodnou
přísnou výstupní cestu přes validated_backend.py. Python backend volá
přímo; HTML jej používá přes same-origin loopback bridge.

Všechny dostupné automatické testy, syntaktické kontroly a statistické
smoke testy prošly.

Tento výsledek NENÍ FIPS, NIST, EUCC ani Common Criteria certifikace.
Testovací prostředí není Windows, proto skutečné BCryptGenRandom a
BCryptGetFipsAlgorithmMode nebylo možné v této kampani živě spustit.
Windows ABI, stavy a chybové cesty jsou testovány řízeným test double;
před formálním použitím je povinný on-target test a externí laboratoř.
Balíček k tomu obsahuje run_windows_cng_live_test.bat; v tomto Linux
prostředí korektně skončil stavem „profil není připraven“ bez výstupu.

Bezpečnostní a lokalizační testy 3.3:

- přísný Python profil nepoužije os.urandom,
- nedostupný profil se nevrátí na hybridní režim,
- vypnutá FIPS zásada negeneruje ani jeden bajt,

  tvrzení,

  hodnoty režimů,
- HTML se přepne čeština → angličtina → čeština,
- změna jazyka zachová již vygenerovaný výstup,
- dynamická validační chyba se v anglickém režimu zobrazí anglicky.

Regrese funkcí 3.1:

7. STATICKÁ BEZPEČNOSTNÍ KONTROLA
---------------------------------

- Generátory nepoužívají Math.random ani nekryptografický modul random.
- Přísný profil přímo volá bcrypt.dll, kontroluje oba NTSTATUS výsledky
  a nepřijímá uživatelský seed.
- Přísná cesta je oddělena před os.urandom/Web Crypto a HMAC logikou.
- HTML CSP povoluje connect-src pouze 'self'; ostatní zdroje mají
  default-src 'none'.
- Bridge naslouchá jen na 127.0.0.1 a náhodném portu.
- Bridge kontroluje Host, Origin, HttpOnly SameSite cookie, JSON pole,
  typy, velikosti a Content-Type.
- CORS a OPTIONS nejsou povoleny.
- Odpovědi mají no-store, nosniff, DENY frame a same-origin politiky.
- Vstupy a názvy souborů se nevkládají jako HTML.
- Externí data se dekódují striktně před kontrolou velikosti.
- Žádný certifikační stav není použit jako dodatečný seed nebo odhad
  entropie.
