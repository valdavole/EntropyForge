Nemusíš nic nastavovat. Automatický režim vždy zachová čerstvý systémový CSPRNG a bezpečně přimíchá dostupné doplňkové zdroje. Přísný Windows profil je oddělený, nepoužívá vlastní směšovač a není vydáván za certifikát celé aplikace.

Náhodná čísla

Podporuje celá čísla až do 2000 číslic; celkový výstup je bezpečně omezen.

Losování možností

V režimu bez opakování se shodné řádky sloučí. S opakováním mohou duplicity sloužit jako váhy.

Silná hesla

Celé heslo se vybírá rovnoměrně. Nevyhovující kandidát se zahodí a vygeneruje znovu.

Tokeny a identifikátory

Platí pro Hex a Base64 URL.

Zdroje a funkční diagnostika

Přidat další externí zdroj

Lze postupně navrstvit až osm souborů z lokálního hardwaru i .efb balíčků vytvořených vzdáleným sběračem. Duplicitní zdroj se odmítne a původní bajty se po jednosměrném zpracování nedrží jako výstupní proud.

Externí zdroj není připojen.

Vzdálený balíček vytvoří samostatný nástroj remote_entropy_collector.py (ve Windows run_remote_collector.bat). Samotný HTML generátor tak zůstává offline.

Pokročilé nastavení zdroje

Automatický režim použije dostupné doplňkové zdroje. Přísný profil je záměrně oddělený: čte Windows CNG přes same-origin lokální bridge, nepřimíchává časování ani externí data a při chybě nepřejde na náhradní zdroj.

Funkční diagnostika zatím nebyla spuštěna.

Co je uvnitř

Bezpečný základ

Běžné režimy stojí na crypto.getRandomValues(); přísný Windows profil čte přímo BCryptGenRandom přes lokální bridge.

Bez zkreslení

Čísla v intervalu používají rejection sampling. Nevzniká drobná nerovnoměrnost způsobená prostým modulo.

Soukromí kláves

U kláves se zpracovává pouze časový odstup a příznak opakování. Znak, keyCode ani text se nesbírá.

Standardní promíchání

Doplňkový proud používá doménově oddělený HMAC‑SHA‑512 a je XORován s čerstvým systémovým proudem.

Poctivé omezení

Certifikace podkladového modulu není certifikací EntropyForge. Časování ani statistika souboru nedostávají automatický odhad entropie.

Fail‑closed profil

Přísný režim se bez lokálního bridge, Windows CNG a zapnuté FIPS zásady neaktivuje a nikdy tiše nepřejde na Web Crypto.

Oddělená síťová vrstva

HTML generátor nepovoluje vzdálená spojení. CSP připouští jen stejný origin lokálního bridge; samostatný sběrač vytváří importovaný .efb balíček.
